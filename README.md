# ELITE Field Kit

A local-first starter kit for open-source intelligence research, evidence handling, and reproducible investigation workflows.

## Mission
Give researchers an inspectable toolkit that runs locally and keeps evidence, provenance, and operator decisions visible.

## Planned capability areas
- Bounded ingestion of explicitly supplied files and records.
- Structural validation and quarantine of malformed or suspicious inputs.
- Hash-based integrity checks with clear limits.
- Source and collection metadata.
- Search over a local catalogue.
- Exportable case bundles and reproducible demonstrations.

## Non-goals
Not an intrusion toolkit, truth oracle, or autonomous attribution engine. Hashes do not establish truth or authorship. Heuristic injection detection is not a security boundary. An accepted record is not necessarily accurate.
