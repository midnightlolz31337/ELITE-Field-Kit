# Quickstart

This repository is currently a documentation and project-structure bootstrap. There is no supported install command or CLI release yet.

## Intended first workflow
1. Create a local case workspace.
2. Record research question, scope, and authorization basis.
3. Import explicitly supplied files into quarantine.
4. Calculate integrity digests and preserve original bytes.
5. Validate structure and record parser/tool versions.
6. Review source metadata and operator decisions.
7. Export a reproducible case bundle.

Treat external content as untrusted data. Never execute ingested files. Work on copies. Avoid collecting personal data beyond a lawful, documented need.
